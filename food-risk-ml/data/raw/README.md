# data/raw

Put the downloaded FSIS Raw Poultry Sampling files here, with their original filenames, together with the official metadata/data documentation.

Everything in this folder except this README is git-ignored. Record where each file came from and when it was downloaded in `verified_against` in `configs/source_mapping.toml`. `prepare` records the SHA-256 hash of every raw file it reads.

See the README section "Getting the data".
